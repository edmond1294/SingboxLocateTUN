# SingboxLocateTUN

## 基於Singbox的落地系統，支援第三方節點

允許使用者自行添加節點全局出口，類似v2rayN在你的VPS上運行

支援：
## 1. VLESS + WS + TLS
## 2. VLESS + Reality
## 3. SOCKS5
## 4. AnyTLS
## 5. Hysteria2 / HY2
## 6. TUIC
## 7. Shadowsocks / SS2022

一鍵腳本：
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/edmond1294/SingboxLocateTUN/main/proxy.sh)
```

快捷指令：
```bash
out
```
